Delphi pays the bills. Almost everything else I write is tooling for Delphi, and that part is in Rust.

I have been on the same all-in-one ERP and CRM since 2017. Not much of my work there is screens. It is async data loading, a scheduler, REST services, a package manager, role and permission administration, and the database update path. On top of that a DUnitX test suite and a layer that drives the application for UI tests.

DDK, the Delphi Devkit, started because I wanted to work on Delphi code in VS Code and nothing existed for it. The other Rust projects came out of the same job. Some of it I write at work, some at home.

Low-frequency radio, or cat as a service

My cats start roaming the moment we arrive at our holiday house, which sits in a village outside Germany. That rules out GPS trackers: they talk to your phone over LTE, and abroad that gets expensive fast. The usual alternative is a radio tracker. I bought one, but it works on high-frequency 2.4 GHz radio, so the range is short and the village is not.

So I am building my own: a static antenna at the house, a handheld one to walk around with, and a LoRa tracker built into the cats' suits.

Home setup
